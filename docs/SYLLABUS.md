# Block Physics — Syllabus & Product Plan

**Learner profile:** age 10, comfortable with arithmetic, fractions, decimals, simple algebra
(solving for one unknown), and factorisation. Loves maths puzzles and physics ideas.

**Track 1: Mechanics** — 10 units, each lesson 10–15 minutes.

---

## 1. Design principles

1. **Play → Predict → Explain → Calculate.** Every idea is first *felt* in a simulation, then
   named, then turned into an equation and practised with numbers.
2. **Real algebra, no trigonometry (yet).** Formulas are written as real equations
   (`v = u + at`) and rearranged to solve for one unknown. Angles are handled with
   "nice" right-angled triangles (3-4-5, 5-12-13) instead of sin/cos.
3. **Maths power-ups.** New maths skills (Pythagoras, square roots, quadratics by factorisation,
   π, scientific notation, inverse-square ratios) are introduced exactly when the physics needs them.
4. **Misconceptions are targeted on purpose.** Each unit has a "trap" question that comes back in
   later reviews until it is answered correctly.
5. **Bite-sized and habit-forming.** Every session is 10–15 minutes and fits a Duolingo-style
   daily streak.
6. **g = 10 m/s²** in Units 1–6 for clean numbers; **g = 9.8 m/s²** introduced as an "Engineer"
   option from Unit 5 onward.

---

## 2. Session types (all 10–15 min)

| Session | Count per unit | Purpose |
|---|---|---|
| **Lesson** | 5 | Teach one idea with sims + practice |
| **Problem Set A — Calculation drills** | 1 | Direct use of the unit's equations |
| **Problem Set B — Word problems** | 1 | Multi-step real-world problems + 1–2 Puzzle Corner problems |
| **Boss Mission** | 1 | Goal-based sim challenge that combines the whole unit |

≈ 8 sessions per unit × 10 units = **80 sessions** (≈ 16 weeks at 5 sessions/week).

### Lesson anatomy (≈ 12 min)

| Min | Step | Example |
|---|---|---|
| 0–1 | **Warm-up review** — up to 2 questions from earlier lessons (mistakes first), added automatically | "Convert 36 km/h to m/s" |
| 1–2 | **Hook & Predict** — a question asked *before* seeing the answer | "Which lands first: the dropped ball or the fired ball?" |
| 2–6 | **Explore** — interactive sim with sliders / drag / draw | Cannon sim with slow-mo and strobe |
| 6–8 | **Explain & Build the equation** — short comic + drag-the-tiles equation builder | `h = ½ g t²` |
| 8–12 | **Practice** — 6–8 mixed questions (MCQ, numeric with units, equation tiles) | |
| 12 | **Wrap-up** — XP, streak flame, combo bonus, concept card unlocked | |

### Problem sets (≈ 12–15 min)

- 7–9 questions at three tiers: 🟢 **Explorer** (one step), 🟡 **Scientist** (two steps / rearranging),
  🔴 **Engineer** (multi-step, quadratics, unit conversions).
- Each problem is a **parameterised template** → unlimited fresh practice with different numbers.
- Step-by-step hints (free; they only stop the answer counting for the "no hints" quest); full worked solution after answering.
- Answers checked numerically with tolerance **and** units.
- **Puzzle Corner** ⭐: one or two harder, maths-flavoured challenges per unit for bonus emeralds.

## 3. Interaction types (reusable widgets)

| Widget | What the child does |
|---|---|
| **Predict-It** | Commits to a prediction (MCQ or slider) before the sim runs |
| **Sim Sandbox** | Changes mass, speed, angle, g, friction with sliders; play / pause / slow-mo |
| **Mission** | Reaches a goal in a sim (hit the target, stop before the wall, land the rover) |
| **Draw-It** | Draws a distance–time or velocity–time graph, or force arrows |
| **Motion Mapper** | Moves a character with mouse/finger; the graph is drawn live |
| **Drag & Label** | Labels forces on a free-body diagram (受力圖); matches graphs to stories |
| **Equation Builder** | Drags tiles to rearrange a formula and solve for the unknown |
| **Numeric Answer** | Keypad + unit picker; checks value and units |
| **Strobe & Ruler** | Measures positions from a strobe (頻閃) replay to calculate speed / acceleration |
| **Spot the Bug** | Finds the mistake in a "broken" sim or a wrong worked solution |
| **Estimate It** | Fermi-style estimates ("How fast does a cheetah run in km/h?") |
| **Try at Home** | Offline experiment card (drop two balls, time with a phone) → bonus XP |

## 4. Gamification (Duolingo-style)

| Feature | Design |
|---|---|
| **XP** | Lesson 10, problem set 20, Boss Mission 50 — scaled by accuracy (50–100%). Perfect bonus +5 / +10 / +20 |
| **Daily goal** | Choose 10 / 20 / 30 / 50 XP per day (about 10 / 15 / 25 / 40 minutes); a bar fills up on the home screen |
| **Streak 🔥** | ≥ 1 session per day keeps the streak; achievements at 3 / 7 / 30 days |
| **Streak Freeze** | Bought with emeralds (hold up to 2); each one protects one missed day |
| **Emeralds** | 2 per session (+2 perfect, +5 boss, +5 daily goal, +5 per Puzzle Corner); spent on freezes, XP potions and skins for Pip |
| **Combo bonus** | From 5 correct in a row, each correct answer gives +1 XP; 8 in a row unlocks *On Fire* |
| **Session badges** | Replaying a session upgrades its badge: iron → gold → diamond (★ for a perfect run) |
| **Daily quests** | 3 a day, e.g. "Earn 20 XP", "Get 5 answers right in a row", "Solve 3 calculations without hints" |
| **Achievements** | 13, e.g. *Galileo* (5 correct predictions), *Puzzle Master*, *Von Neumann*, *Motion Master*, *River Captain* |
| **Boss pass mark** | The mission must be completed (not skipped) and ≥ 60% of the questions right first time |
| **Skill decay & review** | Old lessons "crack" after some days; reviewing them restores them and gives XP (spaced repetition) |
| **Mistake bank** | Wrong answers come back later as review questions |
| **Leagues (not built yet)** | Family league or "beat your own last week" — no strangers |
| **No hearts lockout** | Mistakes never block learning (Challenge Mode with 3 lives is a later idea) |
| **Parent corner** | Accuracy per concept, surprising predictions, 14-day history; grown-up settings behind a maths gate |

## 5. The 10 units

Each unit lists: lessons → problem sets → Boss Mission. Sample problems show the intended difficulty.

### Unit 1 — Describing Motion
*Maths power-up: unit conversion, rearranging `d = s × t`*

1. **Measuring the world** — SI units, prefixes (km, cm, mm, ms), size-sorting game
2. **Distance vs displacement** (位移) — number-line walker; path vs straight line
3. **Speed** — `speed = distance ÷ time`; race sim (minecart vs Pip, then turtle, chicken, Pip and horse)
4. **Average speed** — multi-leg journeys; trap: average speed ≠ average of speeds
5. **Distance–time graphs** — Motion Mapper; steeper = faster; flat = stopped

**Sample problems**
- 🟢 A train travels 180 km in 1.5 h. Average speed? → **120 km/h**
- 🟡 Convert 72 km/h to m/s. → **20 m/s**
- 🔴 Walk 3 km at 6 km/h, then 3 km at 2 km/h. Average speed? → **3 km/h** (not 4!)

**Boss Mission:** *Railway Delivery* — set the minecart's speed on each leg to reach every station exactly on time.

---

### Unit 2 — Velocity & Relative Motion
*Maths power-up: negative numbers as direction, Pythagoras (3-4-5 triangles), first square roots*

1. **Speed vs velocity** — direction matters; + and − signs on a line
2. **Adding velocities** — velocity arrows tip-to-tail on a moving walkway
3. **Relative motion** — two minecarts, closing speed, "who is moving?"
4. **Crossing the river** — square roots, then Pythagoras gives the resultant (合成) speed
5. **Slope = velocity** — reading velocity from the slope (gradient, 斜率) of a position–time graph

**Sample problems**
- 🟢 Walk at 1.5 m/s on a travelator moving at 1 m/s. Speed relative to the ground? → **2.5 m/s**
- 🟡 Two cars 300 m apart drive towards each other at 20 m/s and 10 m/s. When do they meet? → **10 s**
- 🔴 A boat heads straight across a 40 m river at 4 m/s; the river flows at 3 m/s. Actual speed, crossing time, and drift downstream? → **5 m/s, 10 s, 30 m**
- ⭐ *Puzzle Corner (the von Neumann bee):* Two trains 100 km apart approach at 50 km/h each. A bee zooms between them at 75 km/h until they meet. Total distance flown? → **75 km**

**Boss Mission:** *River Rescue* — the boat always points straight across, so choose the launch point that lets the current carry it to each stranded swimmer. (Choosing a heading needs trigonometry, so it waits for a later unit.)

---

### Unit 3 — Acceleration & Motion Graphs
*Maths power-up: more square roots, area under a graph, quadratics by factorisation*

1. **What is acceleration?** — `a = (v − u) ÷ t`; car dashboard sim
2. **Slowing down** — negative acceleration (deceleration, 減速); braking sim
3. **Velocity–time graphs** — slope = acceleration, area = distance (counting squares)
4. **Equations from graphs** — derive `v = u + at` and `s = ½(u + v)t` from the area
5. **The power equations** — `s = ut + ½at²`, `v² = u² + 2as`; stopping-distance game

**Sample problems**
- 🟢 A car goes from 0 to 30 m/s in 6 s. Acceleration? → **5 m/s²**
- 🟡 Braking from 20 m/s at 5 m/s². Braking distance? → **40 m**. At double the speed? → **160 m** (×4!)
- 🔴 A car at 4 m/s accelerates at 2 m/s². When has it travelled 21 m?
  `21 = 4t + t²` → `(t + 7)(t − 3) = 0` → **t = 3 s**

**Boss Mission:** *Traffic Light Challenge* — accelerate and brake to stop exactly on the line.

---

### Unit 4 — Forces & Newton's Laws
*Maths power-up: adding/subtracting arrows, resultant force*

1. **Forces are pushes and pulls** — newtons (N), force arrows, free-body diagrams
2. **Newton's 1st law** — balanced forces, inertia (慣性); frictionless space-skater sim
3. **Newton's 2nd law** — `F = ma`, resultant force; push carts of different mass
4. **Friction** — surfaces, grip, why brakes and shoes need it; ice vs carpet
5. **Newton's 3rd law** — action–reaction pairs; rockets, swimming, walking

**Sample problems**
- 🟢 A 1200 kg car has a resultant force of 3600 N. Acceleration? → **3 m/s²**
- 🟡 Push a 10 kg box with 50 N; friction is 30 N. Acceleration? → **2 m/s²**
- 🔴 A 2 kg trolley accelerates at 1.5 m/s² while friction is 4 N. How hard are you pushing? → **7 N**

**Boss Mission:** *Ice Hockey Physics* — score with the right push, using friction to stop the puck.

---

### Unit 5 — Gravity & Free Fall (g)
*Maths power-up: quadratics in real life*

1. **Mass vs weight** — `W = mg`, g ≈ 10 N/kg; weigh yourself on the Moon, Mars, and Jupiter
2. **Everything falls the same** — Galileo, the Apollo 15 hammer & feather; vacuum chamber sim
3. **Falling equations** — `v = gt`, `h = ½gt²`; drop-a-stone-into-a-well
4. **Up and down** — throwing upward; symmetry (對稱); max height `h = u² ÷ 2g`
5. **Air resistance** — drag, terminal velocity (終端速度); parachute designer

**Sample problems**
- 🟢 A 30 kg child on the Moon (g = 1.6 N/kg). Weight? → **48 N**
- 🟡 A stone dropped into a well hits the water after 3 s. Depth? → **45 m**
- 🔴 A ball thrown up at 15 m/s. When is it 10 m high?
  `10 = 15t − 5t²` → `(t − 1)(t − 2) = 0` → **1 s (going up) and 2 s (coming down)**
- ⭐ *Puzzle Corner:* You hear the splash 3.15 s after dropping a stone. Sound travels at 300 m/s. How deep is the well?
  `t² + 60t − 189 = 0` → `(t + 63)(t − 3) = 0` → fall time 3 s → **45 m**

**Boss Mission:** *Egg Drop Lab* — choose the height and parachute so the egg lands below a safe speed.

---

### Unit 6 — Projectile Motion
*Maths power-up: splitting a velocity into components with 3-4-5 triangles*

1. **Drop vs shoot** — horizontal and vertical motions are independent (strobe replay)
2. **Off the cliff** — horizontal launches; fall time from height, distance from horizontal speed
3. **Angled launches** — split velocity with nice triangles (25 m/s at 3-4-5 → 20 sideways, 15 up)
4. **Range & height** — time of flight, range, max height; discover experimentally that 45° gives the longest range
5. **Aim & fire** — target practice: basketball shot, cannon, water fountain

**Sample problems**
- 🟢 A ball rolls off a 20 m cliff at 8 m/s. Time to land? → **2 s**. How far out? → **16 m**
- 🟡 Launched with 20 m/s sideways and 15 m/s up. Time of flight? → **3 s**. Range? → **60 m**
- 🔴 Same launch: maximum height? → **11.25 m**. Where is the ball at t = 1 s? → **(20 m, 10 m)**

**Boss Mission:** *Castle Siege* — pick speed and angle to land a cannonball on targets at different distances.

---

### Unit 7 — Circular Motion
*Maths power-up: π, circumference, period*

1. **Going round** — speed = `2πr ÷ T`; constant speed but changing velocity
2. **Centripetal force** (向心力) — what pulls things inward (string, friction, gravity); cut-the-string sim shows the tangent (切線) path
3. **How much force?** — `a = v² ÷ r`, `F = mv² ÷ r`
4. **Loops & rides** — loop-the-loop; minimum speed at the top `v² = gr`; feeling heavier or lighter
5. **Cornering** — cars on bends, friction limits, why roads are banked

**Sample problems**
- 🟢 Merry-go-round radius 3 m, one turn every 6 s. Speed? → **π ≈ 3.14 m/s**
- 🟡 A 0.5 kg ball on a 1 m string at 4 m/s. Tension needed? → **8 N**
- 🔴 A loop of radius 10 m. Minimum speed at the top? → **10 m/s**. Minimum release height (frictionless)? → **25 m** (uses Unit 9; unlocks later)

**Boss Mission:** *Roller-Coaster Designer* — build a loop the cart survives.

---

### Unit 8 — Momentum & Collisions
*Maths power-up: conservation equations (balancing before = after)*

1. **Momentum** — `p = mv`; truck vs bicycle
2. **Sticky collisions** — conservation of momentum (動量守恆); bumper-car sim
3. **Explosions & recoil** (後座力) — skater throws a ball, cannon recoil, rockets
4. **Impulse** — `F × t = change in momentum`; airbags, crumple zones, catching an egg
5. **Bouncy vs squishy** — elastic and inelastic collisions; Newton's cradle

**Sample problems**
- 🟢 Momentum of a 50 kg runner at 6 m/s? → **300 kg·m/s**
- 🟡 A 1000 kg car at 20 m/s hits a stationary 1500 kg car; they stick. Speed after? → **8 m/s**
- 🔴 A 0.06 kg egg at 5 m/s stops in 0.01 s (floor) or 0.3 s (pillow). Forces? → **30 N vs 1 N**

**Boss Mission:** *Space Station Docking* — dock gently using small thruster pushes.

---

### Unit 9 — Work, Energy, Power & Simple Machines
*Maths power-up: square roots again, ratios for levers*

1. **Work** — `W = F × d`; joules
2. **Energy stores** — kinetic `½mv²`, gravitational potential `mgh`
3. **Energy is conserved** — roller coaster sim with energy bar charts; `v = √(2gh)` (links to Unit 5)
4. **Power** — `P = W ÷ t`; stair-climbing race, watts
5. **Simple machines** — ramps, levers (moments `F × d`), pulleys; trade force for distance

**Sample problems**
- 🟢 Lift a 20 kg box 1.5 m. Work done? → **300 J**
- 🟡 A coaster starts at rest 45 m high (no friction). Speed at the bottom? → **30 m/s**
- 🔴 A 40 kg child climbs 3 m of stairs in 4 s. Power? → **300 W**
- 🔴 A 600 N rock is 0.5 m from the pivot. Effort applied 2 m from the pivot? → **150 N**

**Boss Mission:** *Pyramid Builder* — move heavy blocks using the best mix of ramps, levers, and pulleys.

---

### Unit 10 — Gravitation, Orbits & Space (capstone)
*Maths power-up: scientific notation, inverse-square ratios*

1. **Why is g different?** — gravity weakens with distance; inverse square law (平方反比定律): double the distance → ¼ the gravity
2. **Newton's cannon** — fire faster and faster until the ball never lands (links Units 6 + 7)
3. **Orbit speed** — near the surface `v² = gr`; astronauts are weightless because they are falling
4. **Satellites** — periods, ISS, GPS, geostationary orbits
5. **Mission planning** — launch, orbit, and travel to the Moon

**Sample problems**
- 🟢 Gravity at twice Earth's radius from its centre? → **2.5 N/kg**
- 🟡 Low-orbit speed with g = 10 m/s², r = 6.4 × 10⁶ m? → **8000 m/s (8 km/s)**
- 🔴 Time for one such orbit? → `2π × 6400 km ÷ 8 km/s` ≈ **84 minutes**

**Boss Mission:** *Launch a Satellite* — choose launch speed and height to reach a stable orbit.

## 6. Extensibility — beyond mechanics

The app separates **engines** (generic code) from **content** (data), so new physics tracks plug in
without rewriting the app.

```
Course: Physics
 └─ Track: Mechanics | Waves & Sound | Light & Optics | Electricity & Magnetism | Heat & Matter | Space
     └─ Unit
         └─ Session (lesson | problem-set | boss)
             └─ Step (predict | sim | explain | question | equation-builder | ...)
```

**Building blocks**

| Layer | Responsibility | Extending it |
|---|---|---|
| **Concept graph** | Concept IDs with prerequisites (e.g. `mech.acceleration` needs `mech.velocity`) | New tracks reference existing concepts (Waves needs `mech.speed`; Electricity reuses `mech.power`; Heat reuses `mech.energy`) |
| **Content files** | Lessons and problem sets as JSON/YAML/MDX | Add files; no code changes |
| **Widget registry** | Reusable interactive components (SimCanvas, Graph, ArrowEditor, EquationBuilder, NumericInput) | New tracks register new widgets (WaveTank, RayOptics, CircuitBuilder) |
| **Physics engine** | Small deterministic integrator for 1D/2D motion | Add new models (springs, waves, fields) |
| **Problem generator** | Parameterised templates → random "nice" numbers, answer function, units, tolerance, hints | Any topic, same format |
| **Gamification engine** | Listens to events (`lessonCompleted`, `answerCorrect`, …) → XP, streaks, quests | Content-agnostic |
| **i18n** | English and Traditional Chinese (繁體中文) string files | Add languages |

**Example problem template**

```json
{
  "id": "mech.free-fall.well-depth",
  "concepts": ["mech.free-fall"],
  "tier": "scientist",
  "params": { "t": { "values": [1, 2, 3, 4] }, "g": { "value": 10 } },
  "prompt": "A stone is dropped into a well and hits the water after {t} s. How deep is the well?",
  "answer": { "expr": "0.5 * g * t^2", "unit": "m", "tolerance": 0.01 },
  "hints": ["Which equation links distance, time and g?", "h = ½ g t²"],
  "solution": "h = ½ × {g} × {t}² = {answer} m"
}
```
